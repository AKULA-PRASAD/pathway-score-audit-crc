# Scientific results, figures and interpretation audit

**Date:** 8 November 2026. **Type:** audit and plan only. No model was rerun, no figure was created or replaced, and no result or frozen artifact was modified. This document is local and uncommitted.

**Bottom line:**
- The final report (`docs/PHASE9_CORRECTED_FINAL_REPORT.md`) is scientifically complete as **text and tables**, but it contains **no figures**.
- Every existing figure is either exploratory (Phases 8A–8C) or shows the **superseded, seed-defective as-run campaign** (`reports/phase9/final_project/figures/`).
- None of the primary results is visualised: the corrected ΔC intervals, the hazard ratios, the apparent vs corrected C, calibration, S-7 and the batch sensitivity.
- The project currently reads primarily as a **rigorous computational execution and audit record** with a sound written report, not yet as a complete, visually presented scientific study.

**Distinctions every figure caption must carry:**
- cause-specific hazard ≠ absolute probability or cumulative incidence;
- HR (association) ≠ added discrimination (ΔC);
- apparent ≠ corrected C;
- corrected-ΔC interval ≠ paired interval;
- Wald CI (coefficients) ≠ percentile bootstrap interval (ΔC);
- internal ≠ external validation;
- S-7 = sensitivity, not replication.

## 7. Missing interpretations (relative to this brief)

1. **M1 covariates.**
   - The age spline is not interpretable as a single HR.
   - The chemotherapy HR (1.17, CI includes 1) is confounded by indication and has no causal reading.
   - Stage is the dominant clinical term and is attenuated by batch stratification.
   - This is only partly covered in FR §9.
2. **HR vs discrimination.** A covariate can have an HR ≠ 1 without adding C, and vice versa. This is not stated.
3. **Wald CI vs bootstrap interval.** The two kinds of interval in the report are not contrasted explicitly.
4. **Discovery/CIT structure.** It is only mentioned in text (FR §13). The 99-patient / 29-event CIT partition is not shown alongside the analysis population.
5. **Biology table.** It lacks representation and batch columns in one place (section 6).
6. **Figures.** No figure legends or captions exist for any current result.

## 8. Figure-generation reproducibility plan (proposed; needs approval)

- **New script.** `scripts/49_make_results_figures.py` (outside the freeze) reads only:
  - CIR;
  - EX and the S-7 results JSON;
  - the checkpoints, read-only, for the outer distributions;
  - the Phase 1, 2, 7C and 8A–8C CSV and JSON outputs.

  It fits no model.
- **Outputs.** It writes `reports/figures/final/Fig{1..9},S{1,2}.{svg,png}` plus `FIGURE_CAPTIONS.md` and `figure_sources.json` (SHA-256 of every input, and the script hash). Files are created exclusively, so no existing figure is overwritten.
- **Determinism.** matplotlib (3.11.2, already installed) with metadata stripped (`metadata={'Date': None}` for SVG/PNG), fixed fonts and fixed figure sizes. Two runs must give identical bytes, or at least identical SVG text.
- **Accessibility.** A colour-blind-safe palette; primary vs sensitivity distinguished by marker shape and fill as well as colour; HR = 1 and ΔC = 0 reference lines; tables of plotted values beside each figure.
- **Test.** `tests/test_results_figures.py` asserts that every plotted number equals its source value. For example, the Fig. 8 endpoints equal `runs.*.percentile_primary`, and the Fig. 6 HRs equal EX.
- **Report integration.** Embed the figures in a results report (section 9). The final report's numbers do not change.
- **Public-release interplay.** Per-sample panels (8A-type distributions, PCA) are aggregate in Figs. 2–3. No sex-inference figure is included (audit D7).
